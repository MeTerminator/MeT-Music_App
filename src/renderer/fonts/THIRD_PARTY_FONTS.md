# Third-party font sources

- `SpotifyMixUITitleVariable.woff2`: https://github.com/MeTerminator/MeT-Music_Player/blob/main/src/fonts/SpotifyMixUITitleVariable.woff2
- `HarmonyOS_Sans_SC.ttf`: supplied with the HarmonyOS Sans license stored in `HarmonyOS_Sans_LICENSE.txt`.
- `SF-Pro.ttf`: https://github.com/sahibjotsaggu/San-Francisco-Pro-Fonts/blob/master/SF-Pro.ttf
- `PingFangSC-*.ttf`: https://github.com/shenweiyan/PingFangSC-Fonts

The two referenced Apple font mirrors do not include an open-source license. Review Apple's font license and redistribution terms before publishing packaged builds.
